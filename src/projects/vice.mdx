# vice

A stealthy AI overlay that operates invisibly atop your screen, integrates with Google Gemini for real-time analysis of text, images, and audio without screen recording detection.

## Features

- **Invisible Overlay**: Runs without being detected
- **Multi-Modal Analysis**: Processes text, images, and audio
- **Google Gemini Integration**: Powered by advanced AI
- **Real-Time Processing**: Instant analysis and insights
- **No Screen Recording**: Non-invasive capture technology

## Tech Stack

- **Language**: Python
- **AI**: Google Gemini API
- **Vision**: Computer vision libraries
- **Overlay**: Custom rendering engine

## Use Cases

- Real-time content analysis
- Accessibility features
- Live translation
- Information extraction
- Smart assistance
