# sandbox-cursor

Run Cursor in a secure Docker sandbox, fully integrated with your system, persistent, and free from trial limits.

## Features

- **Secure Isolation**: Docker containerization for complete environment separation
- **System Integration**: Seamlessly integrates with your host system
- **Persistent Storage**: Maintains your workspace and settings across sessions
- **No Trial Limitations**: Bypass trial restrictions through containerization

## Use Cases

- Development environment isolation
- Testing and experimentation without affecting your main system
- Multi-instance Cursor setups
- Continuous development workflows
