# spine

A Web3 platform built with Solana, FastAPI, and Next.js that enables wallet-connected users to share content stored on IPFS with on-chain reputation features.

## Features

- **Wallet Integration**: Seamless Solana wallet connectivity
- **IPFS Storage**: Decentralized content storage
- **On-Chain Reputation**: Blockchain-based reputation system
- **FastAPI Backend**: High-performance async API
- **Modern Frontend**: Built with Next.js and React

## Tech Stack

- **Blockchain**: Solana
- **Backend**: FastAPI (Python)
- **Frontend**: Next.js, React
- **Storage**: IPFS for decentralized content
- **Smart Contracts**: Solana programs

## Key Features

- Decentralized content sharing
- Wallet-based authentication
- Reputation tracking on-chain
- Fast and responsive UI
