# ironic

Anthropic killing Stainless was pretty sad, so we took matters into our own hands.

Introducing **Ironic** — because it's ironic, get it? Anyway. Ironic generates typed SDKs and MCP servers straight from your OpenAPI spec.

## Why Ironic

- **Stainless-compatible** — if you're migrating from Stainless, Ironic is fully compatible with `stainless.yml`. Just rename your existing `stainless.yml` to `ironic.yml` and you're good to go.
- **Blazingly fast** — generating SDKs and MCP servers takes milliseconds.
- **Inspect before you commit** — preview the resources Ironic will produce before you fully commit to generating them.
- **Completely open source** — no lock-in.

## What It Does

Point Ironic at an OpenAPI spec and it produces:

- **Typed SDKs** for your API
- **MCP servers** so your API is instantly usable by AI agents

It's the toolkit we built for Crosmos's own SDKs and MCP integrations, now open for anyone.
