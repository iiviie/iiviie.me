# crosmos

Crosmos is a context and memory infrastructure for AI agents and teams. We capture knowledge from conversations, documents, and workflows, and structure it into a system agents can query and reason over. This lets agents retrieve relevant context, track changes over time, and operate with persistent, state-aware memory instead of relying on stateless prompts.

Over time, we're building the core infrastructure that lets agents and teams share a unified, continuously evolving understanding of their work.

## How It Works

At the core, Crosmos is a **Monotonic Temporal Knowledge Graph (MTKG)**. Memory is **append-only** — nothing is ever mutated or overwritten in place, which makes the entire history **mutation-free and fully auditable**. You can always trace what an agent knew, and when.

Retrieval is **temporal + semantic**: agents query by meaning and by point-in-time, so they recover not just relevant facts but the relevant *state* of those facts at any moment — instead of a flat snapshot of the present.

## Live in Production

Crosmos is live in production and used by both individual developers and teams building multi-agent systems. We've built a memory and context layer that lets agents persist, retrieve, and evolve context over time instead of relying on stateless calls or basic vector search.
