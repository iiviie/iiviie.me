# Wellfound Role Tracker

A dynamic web scraper that extracts detailed job postings from Wellfound based on a specified role, and prepares structured data for further outreach on LinkedIn.

## Project Overview

This tool automates the search for specific roles (e.g., "Backend Intern") on Wellfound (formerly AngelList Talent), extracts detailed job-related information, and exports the data in a structured format for further research.

## Features

- Automatically search for job roles on Wellfound
- Click and parse each job listing
- Extract:
  - Company Name
  - Job Title
  - Stipend/Salary
  - Tech Stack (from job description)
  - Direct Job Link
- Export results to CSV or JSON
- Generate LinkedIn search URLs for each company

## Tech Stack

- Python 3.10+
- Playwright (browser automation)
- pandas (data export)
- re (regex-based tech stack extraction)

## Functional Requirements

1. Accept a job title input (e.g., "Backend Intern")
2. Navigate to Wellfound and search for the given role
3. Scroll or paginate through job results
4. For each job:
   - Click to open the detailed job description
   - Wait for content to load
   - Extract the required details
5. Save the data in a structured CSV or JSON format
6. Generate LinkedIn company search URLs:
   `https://www.linkedin.com/search/results/companies/?keywords=<company_name>`
