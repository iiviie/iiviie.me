# Hello, World!

Welcome to my first blog post! This post is written in MDX, which means I can use **Markdown** and **React components** together.

## What is MDX?

MDX is a format that lets you seamlessly write JSX in your Markdown documents. You can import components, such as interactive charts or alerts, and embed them within your content.

## Code Example

```python
def hello_world():
    print("Hello, World!")
```

## Using React Components

You can even use React components directly in your MDX files!
